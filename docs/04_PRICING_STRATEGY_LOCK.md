# Pricing Strategy Lock — AODP v1.0

## Philosophy

Bayar sesuai skala bisnis, bukan jumlah fitur.

## Model

1. Implementation Fee
2. Monthly Subscription
3. Custom Development / Continuous Improvement

## Implementation Fee

| Skala Distributor | Setup Fee |
|---|---:|
| Mikro | Rp5.000.000 |
| Kecil | Rp10.000.000 |
| Menengah | Rp20.000.000 |
| Enterprise | Custom |

Implementation disebut sebagai:

**AI Distributor Transformation Program**

Meliputi:

- Business mapping
- SOP mapping
- Import data
- AI configuration
- Training
- Go live
- Pendampingan
