## Purpose

This document defines the official standard for all business documents
generated by the AI Operating Distributor Platform (AODP).

## Core Principles

-   Single Source of Truth (Sales Order)
-   Professional printed documents
-   Intelligent digital metadata
-   Immutable document snapshot
-   Server-side calculations
-   Tenant isolation
-   Audit-first
-   Idempotent document generation
-   Continuous Form support: physical sheet 9.5 x 11 inch, 3 Ply. 3 Ply is
    physical/carbon copy rangkap of the printer -- never HTML panels, never
    HTML transactions. One physical sheet is divided into 2 horizontal
    panels, 9.5 x 5.5 inch each; one panel is one print unit of a document.
    A document that fits one panel's capacity uses one panel; a longer
    document uses several CONTINUATION panels in sequence -- still one
    transaction, one document number, one version (see Revision History,
    23 Juli 2026 "AODP WALUYO -- CONTINUATION PANEL PRINT GATE", superseding
    the prior absolute "one panel = one transaction, no exception" rule).
    One panel never contains parts of two different transactions.

## Standard Flow

Sales Order → Document Engine → PO/Faktur → Delivery Order → Delivery
Verification → Invoice → Collection

## Data Integrity

-   Purchase Order must originate from exactly one Order; no line item
    may be accepted from outside that Order's own order lines.
-   Invoice must be tied to one Order and one Delivery in the same
    chain (delivery.order_id = order.id, same company_id); no delivery
    line from another Order is accepted.
-   Invoice quantity uses verified/accepted delivery quantity, never
    ordered quantity. Partial delivery must never be auto-billed at
    the full ordered quantity.
-   The print renderer only accepts a validated, immutable document
    snapshot -- it never queries the repository/database directly.

## Customer-facing Documents

Printed documents only contain business information required by
customers.

## Internal Metadata

Customer Health, Risk Score, Delivery Verification, Audit Trail,
Approval History, Collection Prediction, GPS, Photos, Voice Notes remain
digital only.

## Mandatory Layout

Header, Customer Information, Item Table, Totals, Footer (Salesman /
Pengirim / Penerima -- three separate signature areas, left to right;
Salesman and Pengirim may be the same person but both areas remain
separate). No "CATATAN" section and no empty notes area anywhere in the
document. No standalone benefit/service footer, form-badge, or copy-strip
section (removed 23 Juli 2026 -- see Revision History).

## Governance

Changes require a new constitution version (v1.1, v1.2, etc.).
