# Sprint 01 — Foundation MVP

## Goal

Build the technical foundation for AI Operating Distributor Platform.

## Scope

- Initialize Next.js TypeScript app
- Setup Tailwind
- Setup database connection
- Create app layout
- Create navigation
- Create core pages
- Create initial database schema
- Create dummy dashboard data

- Business Health Score

- Executive Summary

- App runs locally.
- Navigation works.
- Dashboard renders dummy data.
- Sales page exists.
- Collection page exists.
- WhatsApp page exists.
- Risk page exists.
- Schema file exists.
