# Sprint 03 — Collection Intelligence Basic

## Goal

Create basic collection monitoring and customer risk indicators.

## Features

- Customer credit list
- Invoice due date tracking
- Aging bucket
- Payment status
- Reminder status
- Risk label: Aman / Perhatian / Risiko Tinggi

## Acceptance Criteria

- Owner can see overdue customers.
- Aging bucket is visible.
- Risk status is visible.
- Dashboard shows collection summary.
