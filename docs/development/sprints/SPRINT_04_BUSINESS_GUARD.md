# Sprint 04 — Business Guard AI Basic

## Goal

Create early warning system for owner.

## Features

- Risk alert list
- Discount anomaly placeholder
- Customer behavior change placeholder
- Transaction risk score placeholder
- Alert severity
- Recommended action

## Acceptance Criteria

- Risk alerts can be displayed.
- Alerts have severity and category.
- Dashboard shows open high-risk alerts.
- Owner can mark alert as investigating or resolved.
