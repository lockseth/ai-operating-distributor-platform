# Sprint 02 — FlowSales AI Basic

## Goal

Allow sales daily report input and owner performance summary.

## Features

- Create sales report
- Add product items
- Calculate total value
- Calculate target gap
- Display sales report list
- Generate simple AI summary placeholder

## Acceptance Criteria

- User can input sales report.
- User can add multiple product rows.
- Total value is calculated.
- Report appears in sales list.
- Dashboard shows sales achievement.
