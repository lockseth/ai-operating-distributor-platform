## Catatan Produksi

- **Aset UI nyata** (Scene 2, sebagian Scene 4) harus diambil langsung dari aplikasi berjalan — lihat `demo-video-assets/README.md` untuk cara re-capture.
- **Semua motion graphic "Visi Kami"** sengaja dibuat dengan bahasa visual berbeda dari UI produk asli (tipografi, warna aksen sedikit berbeda) — supaya penonton tidak keliru mengira itu adalah fitur yang sudah berjalan.
- Data yang tampil di semua scene mengacu ke `demo-data.json` — fiktif, bukan data Design Partner asli.
